## English Description

A handy graphical utility built with Python (PyQt5) designed for quickly cropping, scaling, and exporting custom portrait avatars for **Warhammer 40,000: Rogue Trader**.

---

### ✨ Key Features
- **Three Essential Formats**: Automatic setup of standard game resolution presets:
  - `FullLength.png` — 1080 × 1480
  - `Medium.png` — 448 × 600
  - `Small.png` — 260 × 336
- **Interactive Custom Sizes**: Real-time adjustment of frame width and height to fit any mods or personal requirements.
- **Image Controls**:
  - Drag and drop to reposition photos inside the frame.
  - Smooth zooming in/out using the mouse scroll wheel.
- **Responsive Interface**: Clean modern design, multi-monitor scaling support, and dynamic aspect ratio adjustments.
- **Direct Export**: Choose your target directory and export avatars in PNG format with a single click.
- **Localization**: Instant switching between Russian and English UI languages.

## Описание на русском

Удобный инструмент с графическим интерфейсом на Python (PyQt5) для быстрой нарезки, кадрирования и масштабирования аватарок под кастомные портреты в игре Warhammer 40,000: Rogue Trader.

## ✨ Основные возможности
* **Три обязательных формата**: Автоматическая установка стандартных игровых разрешений:
  * `FullLength.png` — 1080 × 1480
  * `Medium.png` — 448 × 600
  * `Small.png` — 260 × 336
* **Интерактивный кастомный размер**: Возможность в реальном времени менять ширину и высоту рамок под любые модификации или личные нужды.
* **Управление изображением**: 
  * Перемещение фотографии внутри рамки с помощью мыши.
  * Масштабирование (приближение/отдаление) с помощью колесика мыши.
* **Адаптивный интерфейс**: Аккуратный дизайн, поддержка разных разрешений мониторов и автоматическая подстройка пропорций рамок.
* **Прямое сохранение**: Выбор папки для сохранения и экспорт готовых аватарок в формате PNG одним кликом.
